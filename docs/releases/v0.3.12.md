# OpenCode Team v0.3.12

This release includes all completed changes integrated on canonical `master`
since v0.3.11. It uses the public, portable package paths; no personal profiles,
credentials, quota state or sessions are distributed.

## BEST

- Reserve request quota atomically before native request preparation. Automatic
  Sol Low/Medium/High selection respects per-window envelopes, reuses its own
  reservation and falls back from High to Medium when High is not admissible.
- Fix transient `quota state locked` contention with large shared histories:
  omit irrelevant lifecycle updates and unchanged state writes; renew the
  acquisition budget only on observed lock progress, with a hard total limit.
- Recover locks only for verified dead owners, with identity checks and
  serialized recovery. Preserve atomic rename, fsync, file security and leases.
- Treat provider safety denials as terminal instead of retrying them.
- Improve independent delegation, standard-procedure discovery, evidence review,
  acceptance-scoped continuations, operator attestations and mandate completion.
  Keep delivery gates distinct from incident closure.

## Release and packaging

- Generate complete preparation and installation handoffs bound to the committed
  archive, exact commit and SHA-256; reject missing files and source drift.
- Run prepublication staging on canonical `master`, retaining exact-commit
  Phase A → immutable tag → official archive → stable-tap installation gates.
- Use the supported macOS 26 runner for source validation.
- Exclude historical temporary browser snapshots from source archives.

## Preserved boundaries

- BEST and FREE remain isolated. FREE retains its integrated anonymous,
  zero-cost `team-free` catalog and role configuration; no paid credentials or
  automatic paid fallback are required.
- No automatic migration of credentials, quota reset, session deletion, personal
  profile rewrite or service restart accompanies installation.
- OpenCode V2 remains an external prerequisite. Governor runtime qualification
  is unchanged: 2.2.5, 2.2.7 and 2.3.2; unknown runtimes are not silently admitted.
- Previous immutable official tags and release archives remain available for
  code rollback. Upgrading the package does not migrate personal data.

## Installation

```sh
brew tap ThomasDanilo96/opencode-team
brew trust --formula ThomasDanilo96/opencode-team/opencode-team
brew install ThomasDanilo96/opencode-team/opencode-team
```

For an existing installation:

```sh
brew update
brew upgrade ThomasDanilo96/opencode-team/opencode-team
opencode-team version
```

The stable formula's SHA-256 is measured from GitHub's immutable `v0.3.12`
source archive after tag publication, not copied from local staging.
